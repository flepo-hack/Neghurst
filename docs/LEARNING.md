## Nothing reported yet

No device has yet contributed a log through [`diagnostics/`](../diagnostics/), so
this file has no measured numbers in it.

That is the honest state, and it is worth being precise about what it means:
**every tuning value in this project is still unverified against a real match.**
The colour thresholds for the player's green ring, the grid resolution, the
dodge distances and the timings are all derived from reasoning about how Brawl
Stars looks, and reasoning has been wrong repeatedly.

Once a log arrives this file reports, from the device itself:

- frames received, rejected and analysed, and the achieved frame rate
- how often the player actually locked
- **for every dodge dispatched, whether the threat stopped being on a collision
  course afterwards** — the number this project has never had
- every distinct error, with counts
- the outcome of every auto calibration attempt, including why it failed

## Known unverified assumptions, in the order they would cause damage

1. The green player signature. If the real ring colour or the surrounding
   palette differs, the player never locks and everything falls back to the
   calibrated anchor.
2. Enemy red marks, and therefore the escape bias away from enemies.
3. Grid geometry, and whether a bullet is more than one cell across.
4. Bullet speed and the dodge timings that follow from it.
5. Brawler top speed, which decides whether a dodge can physically get clear.
6. The own-effect radii, which decide whether real point blank shots survive.
